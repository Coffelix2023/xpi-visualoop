- [ ] 2.5 实现 `prepare` 动作:创建或复用自有目标、按请求设置视口与设备像素比、导航到已校验的回环地址并等待加载;用重复准备、端点被占用、页面离开允许范围三种情况验证行为与既有语义一致。

- [ ] 2.7 实现诊断收集:在 `prepare` 后开启 `Log.enable` 与 `Network.enable`,按 `sessionId` 过滤控制台错误与网络失败,套用现有脱敏与条数上限,未采集到时标记 `unknown`;用受控错误、请求失败、无法取得历史三种情况验证 `unknown` 与「零错误」可区分。
